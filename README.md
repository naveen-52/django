# Django Practice Projects

This repository contains multiple Django practice projects, organized into separate folders:

- **[api_project](./api_project/)**: Django REST API project (students management).
- **[django_curd](./django_curd/)**: Django CRUD operations practice project.
- **[django_curds](./django_curds/)**: Django CRUD implementation with templates.
- **[image_project](./image_project/)**: Django project for image uploads and processing.
- **[imageprocessing](./imageprocessing/)**: Django image processing application with filters and transformations.
